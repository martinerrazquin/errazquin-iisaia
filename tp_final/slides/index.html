El login ya lo resolvimos con Keycloak, pero cuando alguien pide una contraseña, termina pegada en un chat y queda ahí para siempre.

Chismoso agrega un solo paso: en vez del secreto, mandás un link que se puede abrir una vez y solo por la persona correcta.

Cómo funciona

  1. El browser del emisor genera una key nueva y cifra ahí mismo.
  2. Al servidor solo le llega el ciphertext; devuelve un token por destinatario y guarda únicamente su hash.
  3. El link lleva token y key en el #fragment, que el browser nunca envía al servidor.
  4. El receptor se loguea, aprieta Revelar, y el servidor valida token + usuario y consume el grant atómicamente.
  5. El browser del receptor descifra con la key del fragment.

¿Y si…?

Si el link le llega a otra persona: igual tiene que loguearse, y como no es destinatario recibe 404. Si ya se usó, 410.

Si se roban la base: hay ciphertext y hashes de tokens, pero la key nunca pasó por el servidor, así que no se puede descifrar.
